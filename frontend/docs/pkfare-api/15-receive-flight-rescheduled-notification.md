# Receive flight rescheduled notification

Note

1. We recommend you to use orderDetail at this stage since you may have more control over how often and how you want to check the order status and get the ticket number. The best is that you can integrate both of them just for sure.
2. The ticketingNumPush API is used to receive ticket numbers and airline PNRs. Buyer partners should provide a webhook/URL based on the HTTP/HTTPS protocol to PKFARE for this purpose. PKFARE will push ticket numbers when the tickets are issued. In cases where the request is rejected, a rejection reason will be provided.
3. The difference of two PNR parameters:  
   1. PNR: If GDS content, generated by GDS; if LCC and NDC, it is generated by our system just like order number to tag this order.  
   2. airPNR: Customers can use it to retrieve the booking details from airlins website. Only when ticket was issued, you will get the actual airPNR. It may be changed by airlines during issuing.
