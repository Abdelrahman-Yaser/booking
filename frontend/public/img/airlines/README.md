# Airline Logos

This directory contains airline logo images used in the application.

## File Format
- All images should be PNG format with transparent background
- Recommended size: 200x200 pixels
- File naming convention: lowercase IATA code (e.g., `tk.png` for Turkish Airlines)

## Sources
- Primary source: Official airline websites and brand guidelines
- Secondary source: aircodes library logo URLs
- Fallback: avs.io API (`https://pics.avs.io/200/200/{code}@2x.png`)

## Current Airlines
- tk.png - Turkish Airlines
- ms.png - Malaysia Airlines
- sv.png - Saudi Arabian Airlines
- qr.png - Qatar Airways
- ek.png - Emirates

## Adding New Airlines
1. Save the logo as PNG with transparent background
2. Use lowercase IATA code as filename
3. Optimize the image for web use
4. Update this README if adding a major airline
